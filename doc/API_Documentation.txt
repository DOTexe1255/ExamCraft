API Documentation

This document provides an overview of the endpoints available in the backend, including their purpose, sample JSON data, and required headers.

---

1. Authentication Endpoints

1.1 Institute Admin Registration
- Endpoint: POST /api/auth/institute-admin-register
- Purpose: Create an admin user for an existing institute.
- Sample JSON:
  {
    "first_name": "Super",
    "last_name": "Admin",
    "email": "admin@techinst.com",
    "password": "password123",
    "institute_id": 1,
    "phone": "9876543210"
  }
- Headers: None

1.2 Department Admin Registration
- Endpoint: POST /api/auth/department-admin-register
- Purpose: Create a department-level user.
- Sample JSON:
  {
    "first_name": "CS",
    "last_name": "Head",
    "email": "cshead@techinst.com",
    "password": "password123",
    "role": "department",
    "institute_id": 1,
    "department_id": 1,
    "phone": "9876543212"
  }
- Headers: None

1.3 Student Registration
- Endpoint: POST /api/auth/student-register
- Purpose: Register a student under an existing institute and department.
- Sample JSON:
  {
    "first_name": "John",
    "last_name": "Doe",
    "email": "john.doe@techinst.com",
    "password": "password123",
    "role": "student",
    "institute_id": 1,
    "department_id": 1,
    "phone": "9876543214"
  }
- Headers: None

1.4 Unified Login
- Endpoint: POST /api/auth/login
- Purpose: Authenticate admin, department, or student and issue a JWT.
- Sample JSON:
  {
    "email": "admin@techinst.com",
    "password": "password123",
    "role": "admin"
  }
- Headers: None

---

2. Institute Endpoints

2.1 Create Institute
- Endpoint: POST /api/institute
- Purpose: Create a new institute.
- Sample JSON:
  {
    "name": "Tech Institute Pune",
    "code": "TI001",
    "address": "Pune, Maharashtra",
    "contact_email": "admin@techinst.com",
    "phone": "9876543210"
  }
- Headers: None

---

3. Department Endpoints

3.1 Create Department
- Endpoint: POST /api/department
- Purpose: Create a department under an existing institute.
- Sample JSON:
  {
    "institute_id": 1,
    "name": "Computer Science",
    "code": "CS",
    "head_email": "cshead@techinst.com"
  }
- Headers: None

---

4. User Data Endpoints

4.1 Get User Data
- Endpoint: GET /api/user/getuserdata
- Purpose: Retrieve user data from the token.
- Headers:
  {
    "Authorization": "Bearer <JWT_TOKEN>"
  }
- Response:
  {
    "user": {
      "user_id": 1,
      "email": "john.doe@techinst.com",
      "role": "student",
      "first_name": "John",
      "last_name": "Doe",
      "phone": "9876543214",
      "institute_id": 1,
      "department_id": 1,
      "is_active": true,
      "created_at": "2025-12-24T12:00:00Z"
    }
  }

---

Notes
- Ensure that the Authorization header is included for endpoints requiring authentication.
- Replace <JWT_TOKEN> with the actual token received after login.
